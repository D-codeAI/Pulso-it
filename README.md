# PulsoGen IT Academy Website

A modern, responsive, and animated educational landing page built with HTML5, CSS3, and vanilla JavaScript, optimized for GitHub Pages hosting (`https://d-codeai.github.io/Pulso-it/`).

## Features
- **Official Google Form Integration:** Securely captures student enquiries via direct Google Form links.
- **Animated Batch Announcement Flyer:** Features a live countdown timer for the January 2027 batch launch.
- **3 Comprehensive Training Tiers:** Foundation, Foundation + Intermediate, and Advanced (GenAI, ML & GCP).
- **Salary Guide Table:** Illustrative market CTC ranges from ₹2.5 LPA to ₹30 LPA.
- **Theme Support:** Fully functional Light and Dark modes with user preference persistence via `localStorage`.
