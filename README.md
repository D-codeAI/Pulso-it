# PulsoGen IT Academy Website

A modern, responsive, and animated educational landing page built with HTML5, CSS3, and vanilla JavaScript, optimized for GitHub Pages hosting.

## Features
- **3 Comprehensive Training Tiers:** Foundation, Foundation + Intermediate, and Advanced (GenAI, ML & GCP).
- **Salary Guide Table:** Illustrative market CTC ranges from ₹2.5 LPA to ₹30 LPA.
- **Theme Support:** Fully functional Light and Dark modes with user preference persistence via `localStorage`.
- **Responsive Layout:** Clean navigation with a mobile hamburger menu and mobile-optimized tables.
- **Zero Dependencies:** No backend servers, databases, or build frameworks needed.
